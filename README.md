
# Student Performance Prediction and Analysis Using Machine Learning

## 1. Project Overview
This project analyzes student academic-performance data and provides an ML-based performance-category prediction system. It uses the uploaded `StudentsPerformance.csv` dataset and a Random Forest classifier.

## 2. Problem Statement
Educational institutions need simple data-driven tools to understand student performance and identify broad performance categories. This project preprocesses student attributes, performs descriptive analysis, and predicts a student's performance category using machine learning.

## 3. Objectives
- Load and validate student-performance data.
- Preprocess categorical and numerical attributes.
- Perform exploratory analysis and visualization.
- Train a Random Forest classification model.
- Evaluate the model using standard classification metrics.
- Provide an interactive Streamlit dashboard.

## 4. Dataset
The uploaded dataset contains 1000 records and 8 original attributes:
- gender
- race/ethnicity
- parental level of education
- lunch
- test preparation course
- math score
- reading score
- writing score

Derived fields:
- `average_score`: mean of math, reading, and writing scores.
- `performance_category`: Low (0–39), Medium (40–59), High (60–100).

For prediction, the three raw subject scores and derived average are excluded from the input features to avoid target leakage. The model uses student demographic/context fields available in the dataset.

## 14. Design Decisions
- Random Forest is used because it handles nonlinear relationships and mixed feature types well after preprocessing.
- One-hot encoding is used for categorical attributes.
- Standard scaling is applied to numerical inputs.
- A pipeline keeps preprocessing and modeling together and reduces training/inference mismatch.
- Subject scores are excluded from prediction inputs because the target category is derived from those scores.

## 15. Results
A reproducible evaluation is generated by `src/model_evaluation.py`. Run the command above after installation to obtain accuracy, precision, recall, F1-score, confusion matrix, and classification report.

## 16. Limitations
- The target categories are derived from the available subject scores rather than an externally supplied outcome.
- The dataset is a static dataset; real-time student records are outside this project's scope.
- Predictions should be treated as analytical assistance, not as a definitive judgment of a student's ability.
